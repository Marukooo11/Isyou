**适用版本**：智能-问卷4.0.md（真实岗位匹配版）。数据交接格式见《智能-数据字段说明》，样板 output1.sample.json（schema output1.v1.0）。

## 一、评分对象：问卷结构与数据形态

| 部分 | 板块 | 题号 | 内容 |
|---|---|---|---|
| 第零部分 基础信息 | basic_info / 求职开关 | B1–B7 | 年龄段、求学（含专业/毕业年追问）、经历类型（分支入口）、优先段、领域、感受归因、求职状态开关 |
| 第一部分 清晨 | 底色 | Q1、Q3、Q4、Q5 | 尽责×1、外向×1、情绪稳定×2 |
| 第二部分 上午 | 兴趣与能力 | Q6、Q7、Q8、Q10 | 深度投入（核心证据）、助人（核心证据）、转译多选、底色×1 |
| 第三部分 中午 | 情景与环境 | Q11–Q16 | 三方向耐受、环境约束多选、能量账本多选、底色×2 |
| 第四部分 傍晚 | 经历淬炼 | Q18、Q19 | 高光/转折合并叙事（核心证据·CIT）、底色×1 |
| 第五部分 夜晚 | 认知与价值 | Q20、Q22、Q26 | 价值排序、底色×2 |
| 第六部分 补充页 | job_search_profile | J1–J9 | 事实性求职信息（**不参与心理计分**，见第八章） |

**分支规则**：B3 选 F → B4–B6 跳过；B3 勾 ≥2 项 → B4 定 primary_experience；B7 选 C → 第六部分整页跳过，`job_matching_ready = false`。

每题产出的数据形态：

1. **1–7 分**：两端行为锚定，4 分"两边都不像"。
2. **出口项**：不计 0 分、不按中间分计，按各轨道规则处理。
3. **追问项**：可选填文本，B 轨证据主要来源。
4. **多选编码题**：Q8（能力）、Q14（环境）、Q15（能量）；选中项转带编码线索，不产生分数。
5. **提问项**：每题统一提供，不构成证据源。
6. **底色题编码**：〔E/A/C/N/O〕〔+/−〕共 11 题，双编码题 3 题（Q3、Q7、Q11）。

## 三、A 轨：量化分

### 3.1 大五底色分（11 题）

| 维度 | 题目 | 题数 | 分数范围 |
|---|---|---|---|
| 外向性 E | Q3、Q16〔反〕 | 2 | 2–14 |
| 宜人性 A | Q7、Q19〔反〕、Q22 | 3 | 3–21 |
| 尽责性 C | Q1、Q11 | 2 | 2–14 |
| 情绪稳定性 N | Q4〔反〕、Q5 | 2 | 2–14 |
| 开放性 O | Q10、Q26 | 2 | 2–14 |

| 规则 | 内容 |
|---|---|
| 基本计分 | 反向题得分 = 8 − 原始分；维度分 = 各题得分之和 |
| 双编码题 | Q3（陌生人自在）、Q7（助人）、Q11（细节核对）各轨道各计一次，不重复加权 |
| 出口项处理 | 按维度内均值插补；2 题维度出口 ≥1 题 → 该维度标记"低可信"，不出结论；2 题全出 → 维度无效 |
| 定位声明 | 每维 2–3 题取样远低于标准量表；底色分只用于①画像语言②与 B 轨冲突时降级③环境匹配粗筛；人格画像以 B 轨证据为主。C 维度无反向题，标注"无对偶校验" |

### 3.2 情景与价值分

单题保留 1–7 分原始值，直接转译：Q11 ≥ 6 → "重复核对耐受高"，≤ 2 → 数据方向排除信号；Q12 ≥ 6 → "开放结构耐受高"；Q13 ≥ 6 → "实物成果偏好"；Q20 ≥ 6 → "环境优先于收入"硬约束；Q5 ≤ 2 → "抗压短板"提示。

多选编码：**Q8**（A 独立深度 / B 细节校验 / C 自学 / D 规则明确 / E 面向他人 / F 流程执行 / G 自填）；**Q14**（A 感官 / B 任务切换 / C 沟通方式 / D 规则明确度 / E 支持需求 / F 披露选择 / G 远程偏好 / H 自填）；**Q15**（充电 A1 创作 / A2 研究 / A3 调试 / A4 整理 / A5 独自执行 / A6 助人 / A7 自填；耗电 B1 会议 / B2 临时通话 / B3 切换 / B4 需求不明 / B5 长社交 / B6 嘈杂 / B7 自填）。

## 四、B 轨：证据分（CIT 关键事件法）

### 4.1 证据单元（EU）

追问项中每一个符合"**情境＋行为＋结果**"的记录 = 1 个证据单元。Q18 追问项是标准 EU 模板（含"重来会改什么"）。

### 4.2 证据强度

- **3 级（强）**：具体时间场合＋可观察行为＋可验证结果（产出物、他人反馈）。
- **2 级（中）**：有行为和结果，缺情境细节。
- **1 级（弱）**：仅概括自评。**1 级证据不得单独支撑任何推荐结论。**

### 4.3 证据源清单

| 级别 | 来源 | 说明 |
|---|---|---|
| 核心证据源 | **Q6 追问①②**、**Q7 追问**、**Q18 追问（CIT 四问）** | 最可能产出 2–3 级 EU；零经历者主要靠这三处 |
| **结构化经历源** | **J1（起止/时长/单位）、J2（任务/工具/结果）** | 求职者专属；直接落 job_search_profile.experiences[]，同时按 EU 入库（J2"可验证结果"一项通常即 3 级证据） |
| 方向证据源 | Q11、Q13 追问；三个 Quest 的感受分＋注释 | 与方向直接对应 |
| 归因证据源 | B6 追问①（任务 vs 环境）、②③ | ①决定 C 轨加减方向，是全卷关键判据 |
| 补充证据源 | Q3、Q5、Q10、Q20、Q26 的追问项 | 多为 1 级，用于交叉印证 |

### 4.4 能力线索生成与溯源

每条线索写成"**判断＋依据（来自 Q__ 的证据）**"；A/B 冲突（如 Q11 高分但无细节类证据）降级为"待验证线索"进 `unverified_clues`；所有条目可"认可/修正/拒绝/不确定"。

## 五、C 轨：背景轨（第零部分）

规则与 3.0 一致：B1–B6 不进人格分、不作否决项。

**方向建议分 = 情景耐受分（Q11/Q12/Q13 ×2）＋ 证据分（该方向 EU 强度和，上限 6）＋ 背景调整（−2 ～ +3）**

| 情形 | 调整值 | 标注 |
|---|---|---|
| 做过同性质工作（B5），B6 ≥ 5 | +3 | 已验证适配 |
| 同性质，B6 = 3–4 | +1 | 有过接触，中性体验 |
| 同性质，B6 ≤ 2，难受来自**任务本身**（B6 追问①） | −2 | 建议排除（同类任务不适） |
| 同性质，B6 ≤ 2，难受来自**环境**，且该方向通过 Q14 环境校验 | 0 | **同类不同岗**：排除的是岗位环境，不是领域 |
| 无工作经历（B3 仅 E/F） | 0 | 零经验起点，从 30 分钟轻量 Quest 起步 |

环境型不适永远不排除领域，只用于同领域内换岗位类型。年龄/教育分层同 3.0（18 岁以下只推线上 Quest；18–24 入门岗加权；31+ 优先可迁移方向；B2=G 偏作品集导向）。

### 6.2 文本证据线索与判定规则

文本线索词表与 3.0 相同（写作/编程/绘画/修理/乐器/倾听/复盘/收集分类等）。判定阈值不变：

| 判定 | 条件（D_q=定向均分，D_e=证据分和） |
|---|---|
| 突出优势 | （D_q ≥ 5.5 且 D_e ≥ 2）或 D_e ≥ 3（含至少一条 2 级以上证据） |
| 潜在优势 | D_q ≥ 5.5 但 D_e ≤ 1；或 D_e = 2 且 D_q ≥ 4.5 |
| 不构成突出优势 | 有定向分或证据，未达阈值 |
| 难以判断 | 无定向题且无文本证据 |

## 七、综合输出规则

1. **价值前置**：答完 Q6–Q8（约 4 分钟）即输出首批能力线索。
2. **方向建议**：按第五章公式生成，每条附依据；排除项 = Q11–Q13 中 ≤2 分且未被"同类不同岗"豁免的方向。
3. **Quest 匹配**：优先推送与已验证线索同方向的 Quest；Quest 感受分作为新 EU 纳入迭代。
4. **分群**：B7 选 A/B 且 B3 含 A（全职）→ 主线 B（差距拆解）；B7 选 C → 停留主线 A（方向探索），画像页可随时补答 B7 与 J 页触发重算。
5. **创伤保护**：Q18"不愿回顾"出口累计触发 ≥2 次 → 提示可暂停，不再追问该层。
6. **智能画像**：D 轨判定写入画像（附依据与覆盖度标注）。
7. **数据交付**：按《智能-数据字段说明》输出 output1.v1.0 结构 JSON；`meta.data_quality_checks` 四项（valid_json / five_occupations_present / critical_job_search_fields_complete / user_confirmation_complete）全部通过方可交付下游。

## 八、第六部分补充页（资格事实层）的处理

**补充页不参与四轨心理计分。** 它是事实登记，直接落入 `job_search_profile`，并按以下规则决定真实岗位匹配是否可用：

### 8.1 job_matching_ready 判定

以下条件**全部**满足时 `job_matching_ready = true`，否则 false 并在 `missing_critical_fields` 中逐项列明：

1. B7 ∈ {A, B}（求职中）；
2. `consent.can_use_for_job_matching = true`（J9 第一项勾选）；
3. 关键字段非空：`education.highest_level`（B2 已有）、`location_preferences.current_city`（J5）、`employment_preferences.target_seniority` 与 `employment_types`（J6）、`compensation.minimum_amount`（J7）；
4. `experiences` 与 `skills` 至少一项非空（J1–J3 或 B3/E 生活证据可顶替：无经历者允许 `experiences=[]` 但需 `skills` 非空或 Q6 追问①产出 ≥2 级 EU）。

任一不满足 → 对应字段名写入 `missing_critical_fields`（如 `"job_search_profile.location_preferences.current_city"`）。**未知信息一律按不满足处理，禁止猜测或用默认值顶替。**

### 8.2 recommended_occupations 生成规则（必须恰好 5 条）

当 `job_matching_ready = true`：

1. 起点 = `occupation_match` 全量排序结果；
2. **occupation 层硬否决（永不松绑）**：客户面向硬约束 vs 人际智能首要标签；不接受频繁出差 vs 出差频繁；资格要求（医师/法律/财会金融/药师兽医等执业资格、教师资格、驾驶执照）与画像 eligibility 无匹配即否决——未知按不满足处理；
3. **occupation 层降级与过滤**：环境冲突（噪音/打断/远程）每条把 verdict 降一级并记入 env_demotions；"需经验资历"职业对入门用户（fresh/entry 或相关经验 <12 月）暂缓；
4. **JD 层过滤（由 handoff 消费方在真实岗位层执行，职业库无对应数据）**：地点（J5 城市/搬迁/通勤/办公方式）、行业排除（J8 excluded）、雇佣类型与职级（J6）、薪资下限（J7，`negotiable=true` 时为软约束）；
5. 通过者按 match_score 降序取 5 条；**不足 5 条时按松绑顺序回填**（每松一层记 warnings）：verdict 门槛放宽至 hold → 松绑职级过滤（该条 current_readiness 强制 exploration_only）；资格/出差/客户面向否决与非职业条目排除永不松绑；
4. 每条输出 16 属性（rank / occupation_id / occupation_name / recommendation_type / match_score / confidence / user_status / reason[] / search_titles[] / search_keywords[] / negative_keywords[] / current_readiness / matched_readiness_information[] / missing_readiness_information[]），其中：
   - `current_readiness` 三档：`ready`（相关经历＋技能均有 3 级证据）、`partially_ready`（有部分匹配证据）、`exploration_only`（仅方向匹配，无 readiness 证据）；
   - `matched/missing_readiness_information` 从 experiences、skills、portfolio、languages 中比对生成；
   - `negative_keywords` 由 constraints（含 Q3/Q16 client_facing=avoid、J8 排除项、Q14 环境编码）翻译为检索排除词；
5. `job_matching_ready = false` 时 **recommended_occupations 输出空数组**（不生成半成品推荐），前端提示补齐 `missing_critical_fields` 后重算。

### 8.3 consent 与敏感信息

J9 三个勾选框分别映射 `can_use_for_job_matching`、`can_use_for_web_job_search`、`sensitive_info_requires_confirmation`；`can_generate_external_materials` 与 `can_share_sensitive_information_externally` 默认 false，仅在用户显式开启时置 true；`behavior_inference_enabled` 默认 false（行为推断类能力必须单独授权）。Q14-F 的披露选择只进画像与环境过滤，**不经用户逐次确认不得对外输出**。

### 8.4 录入辅助机制（回显卡片＋预填草稿）的计分定位

J1/J2 配有两项录入辅助：回显卡片（回显 B4/B5/B6.f3，可就地修改）与预填草稿（从用户自己在 B6.f3、Q6、Q18 追问里写的文本解析候选值）。计分与就绪判定规则：

1. **草稿未经用户确认 ＝ 未提供**：按缺失处理，计入 missing_critical_fields，不因存在草稿而放宽 8.1 判定；
2. **确认后按 user_reported 事实入库**：source 记 `user_reported`（不是推断），J2"可验证结果"原文同步生成 EU；
3. **草稿来源红线**：只能解析该用户自己的作答原话，禁止默认值、行业常识、外部数据——本机制不改变"未知信息不得按满足处理"的全局红线。

## 九、信度自检与可信度标注

- **对偶校验**（反向换算后差值 ≥5 → 请用户复核其中一题）：外向性 Q3 vs Q16；情绪稳定性 Q4 vs Q5（小岔子 vs 真麻烦）；宜人性 Q22 vs Q19。
- **无对偶维度**：尽责性（Q1、Q11 均为正向）、开放性（Q10、Q26 均为正向）标注"内部一致性未校验"，以 Q1 与 Q11、Q10 与 Q26 做概念交叉印证。
- **出口项比例** > 30% → 整体"低可信，仅供参考"，`meta.low_confidence_overall = true`。
- D 轨音乐、空间、自然认知仅凭文本证据；无证据即"难以判断"，不推测。
- 补充页跳过率进 `profile_status.warnings`（如"薪资期望缺失，已列入 missing_critical_fields"），不影响心理轨道可信度。
