# 《我的一天》——ASD职业探索问卷 V4.0（真实岗位匹配版）

## 问卷说明

本问卷把提问放进"一个普通的一天"的情景里。你只需要回答：**在这样的时刻，你通常是什么样、会怎么做。**

规则（对被试）：

1. 回答**当下的日常状态**，不是你希望自己成为的样子。
2. 评分题为 1–7 分，1 分和 7 分都写了行为锚定，中间分数介于两者之间。
3. 每题都有 **出口项**（不了解 / 没经历过 / 不想说），选它不扣分、不影响结果。
4. 带 **追问项** 的题目：愿意就写一件具体的事（什么时候、发生了什么、结果如何），写下的经历是能力线索的**证据**，比分数更重要。
5. 任何一题可跳过，可暂停，进度不丢失。
6. **每题下方统一提供"提问项"**（对题目本身有疑问就写，系统先解释再请你作答），前端统一渲染，不在每题重复印出。
7. 基础信息全部可选"不想说"，按"未知"处理。
8. **第六部分（真实岗位匹配补充页）只在 B7 选了"正在找 / 近三个月打算找"时出现**。它是事实性问题（城市、薪资、技能），不是心理题；跳过的项系统记为"缺失"，**不会猜**。

## 第一部分 清晨（底色，4 题）

### Q1 闹钟响起的半小时 〔C+〕
情景：早晨醒来，今天没有任何必须几点到的安排。
"我会按惯常的顺序开始这一天（固定顺序洗漱、吃固定的早餐、先做同一件事），而不是随当天心情临时安排。"
- 1 分 = 几乎每天开始顺序都不一样，经常出门前才临时决定第一步
- 7 分 = 早晨有一套雷打不动的顺序，被打乱会明显不适；我习惯按计划和日程行事
- ○ 不了解 / 说不好

### Q3 和陌生人打交道 〔E+〕
情景：上午，一个不太熟的人需要和你打交道——必须回复的消息，或当面问事、办手续。
"这种时候我比较自在。"
- 1 分 = 一条普通消息能纠结几个小时不敢回，当面更想躲开
- 7 分 = 线上线下都自在，几分钟处理好，不觉得消耗
- ○ 不了解 / 没经历过
- 追问项：哪一类陌生人场合最难？哪一类其实还好？＿＿＿＿

### Q4 出门前的小岔子 〔N−〕
情景：早上出门前出了小岔子（东西找不到、车晚点、计划被打乱）。
"我很容易因此烦躁，半天缓不过来。"
- 1 分 = 岔子对我毫无影响，换方案就是
- 7 分 = 一点小岔子就能毁掉我一上午的心情
- ○ 不了解 / 说不好

### Q5 早上遇到真正的麻烦 〔N+〕
情景：早上遇到一个真正的麻烦（东西坏了、事情黄了、一醒来就收到坏消息）。
"大部分时候我心态是放松的，能就事论事处理。"
- 1 分 = 一有麻烦我就慌，情绪先于处理
- 7 分 = 越有麻烦我越冷静，处理完情绪没受影响
- ○ 不了解
- 追问项：最近一次大麻烦是什么？你先做了什么？＿＿＿＿

## 第二部分 上午（兴趣与能力，4 题）

### Q6 深入状态（核心证据题）
情景：上午有整块自由时间，你手上有一件自己感兴趣的事（爱好、项目、研究、收集，什么都算）。
"我会进入长时间的专注状态，一抬头几个小时过去了。"
- 1 分 = 目前没有能让我投入几小时的事，或总是浅浅碰一下就放下
- 7 分 = 经常一投入就是 3 小时以上，被打断会烦躁，甚至忘记吃饭

### Q7 帮别人解决问题 〔A+〕（核心证据题）
情景：上午有人带着一个具体问题来问你（修东西、查资料、改文案、出主意都算），正好在你擅长的范围内。

- 1 分 = 通常回避这类请求，或答应了经常没解决
- 7 分 = 这类请求几乎都接，愿意为它调整时间，大多数人反馈"确实解决了"
- ○ 不了解 / 没人问过我
- 追问项：最近一次被请教是什么问题？你怎么解决的？＿＿＿＿

**Quest-2（可选，约 60 分钟）**：任选一个你熟悉的领域，写 500 字"为什么 X 会这样"的短分析。

### Q13 手工/技术/实操方向的中午

## 第六部分 真实岗位匹配补充页（J1–J9 · 仅当 B7 选 A/B）

> 引导语：这一页和前面不一样——前面是了解"你是什么样的人"，这一页收集找工作要用的**硬信息**（城市、薪资、技能、证书）。全部为事实性问题。任何一题都可以跳过，但跳过的信息将被记入"缺失信息"，系统**不会替你猜**；缺失关键信息时将无法进行真实岗位匹配。除 J1/J2 针对 B4 所选那段经历外，没有工作经历的人同样适用（项目、爱好、自学都算）。

> **回显卡片**：J1 顶部会显示你在第零部分讲过的那段经历——类型（B4）、领域（B5）、你写的一句话描述（B6 追问③）。你不需要记得自己选过什么；显示出来的内容可以直接修改，修改会写回你的画像。
>
> **预填草稿**：如果你在 B6 追问③、Q6 或 Q18 的追问里写过这段经历的内容，系统会把**你自己写的原话**解析成 J1/J2 的草稿（比如岗位名、做了多久、做出了什么），并标上"根据你之前写的，待确认"。草稿只来自你的原话，系统不会替你编造；你确认之前，草稿就当不存在（对应字段仍为空）。

### J1 主经历登记（结构化填空）
针对你在 B4 选的那段经历（没选的话，写你最正式的一段项目/爱好）：

- 岗位或项目名称：＿＿＿＿
- 单位/学校/平台（可模糊到"某电商公司"）：＿＿＿＿
- 起止时间（如 2025-06 至 2025-09，进行中写"至今"）：＿＿＿＿
- 投入程度：总共约＿＿个月，每周约＿＿小时（估不准可空）

### J2 主经历内容
- 主要做了什么（1–3 条，尽量动词开头，如"整理销售数据""维护经营周报"）：＿＿＿＿
- 用过的工具/软件/设备（如 Excel、SQL、某型号机床）：＿＿＿＿
- 做出了什么可验证的结果（作品、数量、别人反馈，如"完成 12 期周报""独立查出 30 处数据错误"）：＿＿＿＿
- 追问（选填）：还有其他工作/实习/项目吗？每段一行（名称＋起止＋一句话）：＿＿＿＿

### J3 技能清单
列出你最有把握的 **2–5 项谋生技能**（软件、工具、手艺、语言都算），每项标一个水平，并注明最近半年是否用过：

- 3 = 能独立完成较复杂的任务
- 2 = 能独立完成常规任务
- 1 = 入门，需要指导

格式示例：`SQL：3，近期用过；Excel：3，近期用过；Python：1，半年未用`＿＿＿＿

### J4 语言与证书
- 普通话之外的语言及水平（如"英语 CET-6""日语 N2"，无则空）：＿＿＿＿
- 证书/执照（计算机等级、会计、教资、驾照等，无则空）：＿＿＿＿

### J5 地点与办公方式
- 当前城市：＿＿＿＿
- 优先城市（可多个）：＿＿＿＿；可以接受的城市：＿＿＿＿
- 为合适的工作换城市：愿意 / 看条件 / 不愿意
- 单程通勤上限（分钟，如 60）：＿＿＿＿
- 可接受的办公方式（多选）：A 到岗　B 混合　C 远程
- 出差接受度：不接受 / 偶尔可以 / 经常也行

### J6 求职状态与类型
- 目标职级（多选）：实习 / 应届-初级 / 有经验者 / 都可以
- 雇佣类型（多选）：全职 / 兼职 / 实习 / 自由职业接单
- 最早可入职时间（如 2026-09-15，待定可空）：＿＿＿＿
- 每周可工作小时数：＿＿＿＿
- 能否接受自由职业（能 / 不能）；能否接受工作量不稳定（能 / 不能）

### J7 薪资期望
- 最低可接受月薪（税前，元）：＿＿＿＿
- 期望月薪（税前，元）：＿＿＿＿
- 有商量余地吗：可以谈 / 很难让步

### J8 行业偏好
- 偏好行业（如 互联网、电商、制造业，可空）：＿＿＿＿
- 可接受行业：＿＿＿＿；排除行业：＿＿＿＿
- 能否接受外包岗位（能 / 不能）；能否接受劳务派遣（能 / 不能）

### J9 核对与授权
以下信息将用于为你匹配和检索真实岗位，请逐项确认：

- □ 允许使用我的画像信息进行岗位匹配
