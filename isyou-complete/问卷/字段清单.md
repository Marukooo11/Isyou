# 智能-问卷4.0 字段清单（v2）

**用途**：① 说明相对 3.0 删除了哪些字段及原因；② 给出 4.0 全量字段汇总索引。配合《智能-数据字段说明.md》与样板 `output1.sample.json`（schema output1.v1.0）使用。

### 3.10 occupation_match[]（13 属性/条）与 recommended_occupations[]（16 属性/条）

- occupation_match：occupation_id、name、match_score、verdict、big5_match、intelligence_match_norm、matched_dimensions、conflict_dimensions、skipped_dimensions[]、matched_intelligences[]、env_demotions[]（环境冲突降级原因）、confidence、basis[]、user_status（规则见数据字段说明附录 A；职业库 schema 1.1 新增 environment_tags / typical_seniority / credential_required 三组标签及其消费规则）。
- recommended_occupations：rank、occupation_id、occupation_name、recommendation_type、match_score、confidence、user_status、reason[]、search_titles[]、search_keywords[]、negative_keywords[]、current_readiness、matched_readiness_information[]、missing_readiness_information[]。**job_matching_ready=false 时必须为空数组。**

### 3.11 evidence_units[]（8 属性/条）与 unverified_clues[]（3 属性/条）

EU：eu_id、source_question_id（skill 对话来源记 skill_dialog）、text、strength(1–3)、parsed{situation,behavior,result}、linked_capabilities[]、linked_intelligences[]、user_status。线索：clue、reason、source_question_ids。

### 3.12 handoff（3）与 meta（12）

handoff：consumer、allowed_uses[]、required_processing_rules[]。
meta：answered、total_shown、exit_ratio、low_confidence_overall、trauma_guard_triggered、first_clue_delivered、recompute_trigger、generator(intelligent-questionnaire-4.0)、data_quality_checks{valid_json、five_occupations_present、critical_job_search_fields_complete、user_confirmation_complete}。
